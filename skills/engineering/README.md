# Engineering skills

Daily code and technical work.

## User-invoked

- [`close-issue`](./close-issue/SKILL.md) — finish a launched issue and retire its owned workspace
- [`launch-issue`](./launch-issue/SKILL.md) — launch a Tengella issue into a
  Worktrunk checkout and Herdr worker

- [`nightly-builds`](./nightly-builds/SKILL.md) — check Tengella nightly builds
  and diagnose failures; silent when healthy
- [`primer`](./primer/SKILL.md) — create a ready-to-paste prompt for continuing
  current technical work in a fresh agent session
